# CommerceIQ
Predicting future product engagement from early customer reviews (Amazon Reviews 2023, Video Games).

## Setup
1. Download Video_Games.jsonl.gz and meta_Video_Games.jsonl.gz from https://amazon-reviews-2023.github.io/
2. Put both files in one folder together with 01_data_exploration.ipynb
3. pip install -r requirements.txt
4. Run the notebook top to bottom (it creates reviews_clean.parquet, about 5 minutes)
